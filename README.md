# Restoring-Summer
A RestoringSummer egy online játék platform, ahova akárki felrakhatja a játék projektjét. Persze mielőtt publikus lenne a játék, először a moderációs csapat áttekinti a játékot, hogy megfelel-e minden kritériumnak és irányelvnek. A weboldalon lehet játékokat értékelni és ranglistákon szerepelni is.
